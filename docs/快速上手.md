# 科研模式 · 快速上手（生物医学文献检索助手）

一个本地运行的 AI 科研助手：接入 **DeepSeek** 大模型 + **7 个学术文献数据库**（PubMed、Europe PMC、bioRxiv/medRxiv、Crossref、OpenAlex、Semantic Scholar、arXiv），帮你做多库检索、去重排序、证据分级、反证核查，并把结果整理成带 PMID/DOI 的研究日志。

全程无需编程基础：解压 → 双击 → 粘贴 Key → 浏览器里聊天。

---

## 一、安装（约 3–5 分钟）

1. 把收到的 `bioresearch-v0.3.5.zip` 解压到一个**固定位置**（安装后文件夹不要移动、不要放回收站）。
2. **Windows**：双击 `install.bat`（若微信拦截 `.bat`，见常见问题 1；也可以双击 `install.cmd`），会弹出**图形安装窗口**：
   - **安装目录**（Node 便携版 / 文献检索 MCP / 启动脚本）：可直接填写或点「浏览…」选择文件夹（默认 `C:\Users\<你>\bioresearch`）；
   - **DSH 数据目录**（预设 / API Key）：同样可填可选（默认 `C:\Users\<你>\.dsh`）；
   - **勾选「安装/更新 DeepSeek Harness」**：本机已装同版本时自动跳过；不勾选则使用你机器上已装的 dsh；
   - **勾选「安装「科研模式」插件」**：安装预设 + 文献检索 MCP + 设为默认模式（不勾选则只装 DSH 本体）；
   - **DeepSeek API Key**：选填（输入框会遮码，只保存在本机；留空可之后在网页 设置→模型 填写）；
   - 点 **「开始安装」**：进度实时显示在窗口日志里；完成后会询问是否立即启动并打开网页。
   - 文字模式（服务器/排查用）：双击 `install-console.bat`。
   **macOS**：请使用专门的 `bioresearch-v0.3.5-mac.zip`，解压后双击 `一键安装.command`（图形向导，详见包内 `快速上手-mac.md`）；**Linux**：终端里运行 `bash install.sh`（文字模式，同样的路径询问与组件检查）。
3. 安装器会自动检查所有组件，**已装好的自动跳过**（重复运行几秒钟就完成，不会反复重装）：
   - Node.js（检测系统版本，不足才下载便携版）；
   - npm 镜像（已是 npmmirror 就跳过）；
   - DeepSeek Harness（版本一致就跳过，不一致才升级）；
   - MCP 依赖（按 lockfile 哈希校验，一致就跳过）；
   - DeepSeek API Key（已配置就跳过）。
4. 安装完成后浏览器会自动打开 `http://127.0.0.1:3081`（点「是」时）。

> 还没有 DeepSeek API Key？去 [platform.deepseek.com](https://platform.deepseek.com) 注册并创建 API Key（按量付费）。Key 填过之后随时可在网页 **设置 → 模型** 里更换。
> 想改安装路径？重跑 `install.bat`，在窗口里改路径或点「浏览…」重新选择即可（预设会自动重新指向新位置）。

## 二、第一次使用

1. **设置 → 模型**：确认 DeepSeek 卡片里已有 Key（安装时已自动填好）。
2. 选择模型（如 `deepseek-chat`）。
3. **选择工作区**：添加并选中你的项目文件夹（建议新建一个专门的研究目录，日志会写在这里）。
4. 新建会话时，模式默认已是 **「科研模式」**（安装器已写入默认值；已发过消息的旧会话模式固定，新建会话即可）。

## 三、示例任务

直接发给它：

> 检索 2020–2026 年关于「MYH7 突变与肥厚型心肌病」的机制研究与反证，按证据强度分级，输出带 PMID/DOI 的文献卡，写入研究日志。

或者：

> 用 literature_search 检索「TTN truncating variants 与扩张型心肌病」，限 PubMed、Europe PMC、OpenAlex 三个库，返回 10 篇，并报告哪些库失败或限流。

它会自动：制定检索策略（机制 / 方向 / 临床证据 / 反证空间）→ 调 MCP 工具检索 → 给证据分级（A–D）→ 写 `research-log/` 研究日志 → 汇报结论。

## 四、日常使用

- 启动：Windows 双击桌面「deepseek-dsh」快捷方式（或 `C:\Users\<你>\bioresearch\start.bat`）；macOS/Linux 运行 `~/bioresearch/start.sh`。保持那个黑窗口/终端开着即可，关掉即停止服务。
- 端口被占用时：`start.bat 3090` 或 `./start.sh 3090`。
- 研究日志：位于你选的**工作区**目录下的 `research-log/`，每次研究一轮一个 `round-001/` 文件夹，可长期留存、随时翻看。
- 检索历史：保存在本机 `~/.local/state/literature-search-mcp/history.jsonl`（不含摘要与密钥）。

## 五、常见问题

1. **微信拦截 .bat 文件**：微信有时不允许直接发 .bat。发送时把 `install.bat` 改名为 `install.txt` 发送，接收方解压后改回 `install.bat`；或直接双击同目录的 `install.cmd`。
2. **安装时 Node 下载很慢**：先到 [nodejs.org](https://nodejs.org) 手动安装 Node.js 22+（LTS），再重跑安装脚本，脚本会直接使用系统 Node。
3. **终端中文显示乱码**：安装脚本已做编码适配（bat 纯 ASCII、PowerShell 脚本带 BOM），在任何 Windows 区域设置下均不会乱码。若仍看到乱码，说明拿到的是旧版安装包，请用 `bioresearch-v0.3.5.zip` 重新解压安装。
4. **Key 校验失败（401）**：Key 复制错了（多空格/少字符），重新运行安装脚本，或在网页 **设置 → 模型** 里重填。
5. **网页提示 MISSING_CREDENTIAL**：**设置 → 模型** 里给 DeepSeek 填 Key 并保存，立即生效，无需重启。
6. **MCP 没连上 / 检索报错**：终端运行 `node "C:\Users\<你>\bioresearch\literature-search-mcp\dist\server.js"`（macOS/Linux 路径为 `~/bioresearch/literature-search-mcp/dist/server.js`）看报错；最常见是 Node 版本过旧或依赖未装全，重跑 `install.bat` 即可修复。
7. **只有部分数据库出结果**：正常。每次检索结果里有 `source_statuses` 字段：`ok` 成功、`empty` 无匹配、`rate_limited` 被限流、`timeout` 超时。单库失败不影响整体，可收窄 `sources`、降低 `limit` 或稍后重试。
8. **升级新版**：收到新 zip 后解压覆盖旧位置，重跑 `install.bat`/`install.sh`（不会动你的 Key 和研究日志）。
9. **卸载**：运行安装目录里的 `uninstall.bat`/`uninstall.sh`；DSH 本体可用 `npm rm -g @deepseek-ai/dsh` 移除。
10. **Linux 上 agent 执行命令报沙箱错误**：安装 `bubblewrap`（如 `sudo apt install bubblewrap`）后重启服务。
11. **「科研模式」打不开 / 点击后弹回标准模式**：DSH 规定**已发送过消息的会话模式固定**，不能中途切换——新建一个会话即可（安装器已把「科研模式」设为默认，新会话默认就是它）。若新建会话仍失败，双击安装包里的 `diagnose.bat`，把输出发给发你安装包的人定位；也可以在网页 设置 中把默认模式重新选为「科研模式」。

## 六、隐私与成本

- 你的 DeepSeek API Key 只保存在本机 `~/.dsh/.credentials.yaml`（权限 0600），不会上传、不会打进安装包、不会写进日志。
- 模型调用走你的 DeepSeek 账户，按量计费；文献检索走公共学术数据库接口，无需额外付费。
- 所有数据默认只在本机（127.0.0.1），不会开放给局域网或公网。
