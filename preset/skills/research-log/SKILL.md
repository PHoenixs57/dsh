# 研究日志：检索循环的权威记忆

`research-log/` 是**唯一**跨轮可信的记忆。对话上下文是易失的（压缩、重启、派生都会丢），日志不是。**绝不凭对话记忆重建研究状态。**

## 目录结构

```
research-log/
├── index.md            # 每轮一行：轮次、日期、研究问题、结论、链接
├── round-001/
│   ├── hypothesis.md   # 研究问题卡（模板见下）
│   ├── literature.md   # 每条候选结论的文献卡
│   ├── review.md       # 对抗审查报告
│   └── conclusion.md   # 本轮结论 + 下一步
└── round-002/ ...
```

每轮建 `round-NNN/`（三位零填充、按序递增）；每轮结束向 `index.md` 追加一行。

## 研究问题卡（hypothesis.md）

```markdown
# 研究问题 R00N

- **问题陈述**：<一句话：关于 {主题}，{结论} 在 {人群/体系} 中是否成立？>
- **来源**：第 N 轮，来自 <用户提问 / 上一轮修订>
- **检索策略**：<实际跑过的查询、来源库、年份过滤>
- **支持证据**：<PMID/DOI 带等级与方向>
- **反证**：<PMID/DOI 带等级与方向；只有反证空间搜过且为空时才可写“无”，并记录当时搜了什么>
- **置信度**：0.0–1.0 <一句话理由>
- **可证伪预测**：<什么样的后续文献或实验能推翻这条结论>
- **状态**：待查 | 审查中 | 稳定 | 已推翻 | 已被取代
```

## 文献卡（literature.md，每篇实际使用的论文一条）

```markdown
## PMID 12345678 / DOI 10.xxxx/xxx — 第一作者等，年份
- **发现**：<一句话>
- **针对**：<哪条结论>，方向：支持 / 反对 / 中立
- **等级**：A | B | C | D
- **模型体系**：<细胞系 / 小鼠 / 人类队列 / …>
- **注意点**：<样本量、混杂、可复制性>
- **原文摘录**（承重句才抄）："<原句>"
```

## 审查报告（review.md）

由对抗审查者（见 adversarial-review 技能）撰写：发现的问题、严重程度（critical / major / minor）、本轮结论是否存活。

## 本轮结论（conclusion.md）

```markdown
# 第 R00N 轮结论
- **存活的结论**（排序）：<结论、置信度、残余风险>
- **被推翻/降级的结论**：<结论与推翻理由>
- **反证空间**：<搜过哪些负向查询，结果如何>
- **下一步**：<下一轮要查什么、为什么>
```

## 纪律

1. 每轮开始先读 `research-log/index.md` 与最近一轮的 `conclusion.md`。
2. 每轮结束必须写齐四份文件并更新 index。
3. 日志文件是普通 Markdown，路径可读、内容可检索（grep），不要用二进制或截图代替。
4. 用户问“上次查了什么/结论是什么”时，从日志回答，不从记忆回答。
